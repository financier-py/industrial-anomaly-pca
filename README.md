# Industrial Anomaly Detection via PCA Reconstruction

Это проект по поиску аномалий в показаниях промышленных датчиков. Модель обучается только на нормальных данных, поэтому размеченные аномалии для обучения не нужны.

## Зачем это нужно

На производстве заранее неизвестно, как именно может сломаться оборудование. Зато известно, как оно работает в штатном режиме. Идея простая: обучить модель на нормальной работе, а всё, что сильно отличается от нормы, будем считать аномалией.

## Как это работает

PCA запоминает структуру нормальных данных. Когда приходит новый вектор показаний, модель пытается его восстановить через сжатое представление. Нормальные данные восстанавливаются хорошо, а аномалии - плохо. Поэтому по величине ошибки восстановления можно судить о том, насколько вектор похож на нормальный.

$$\text{error} = \|x - \text{PCA reconstruct}(x)\|^2$$

Порог устанавливаем, предполагая нормальное распределение ошибок на нормальных данных. То есть среднее плюс 3 стандартных отклонения от среднего.

## Структура проекта

```
industrial-anomaly-pca/
├── data/
│   ├── raw/                  # исходные данные
│   └── processed/            # графики EDA, ROC-кривая
├── notebooks/
│   └── exploration.ipynb     # EDA и визуализация
├── src/
│   ├── pca_numpy.py          # PCA с нуля на NumPy (SVD)
│   ├── anomaly_detector.py   # fit/predict + threshold
│   └── evaluation.py         # ROC-кривая, метрики
├── pyproject.toml
└── requirements.txt
```

## Запуск

```bash
# если у вас стоит uv:
```
